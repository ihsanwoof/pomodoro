# 🍅 PyQt5 Pomodoro Uygulaması

PyQt5 kullanılarak geliştirilmiş modern ve sade bir masaüstü Pomodoro zamanlayıcı uygulaması.

## 🚀 Özellikler

- **🍅 Pomodoro:** 25 dakikalık odaklanma süresi
- **🌿 Kısa Mola:** 5 dakikalık dinlenme süresi
- **📚 Uzun Mola:** 15 dakikalık dinlenme süresi
- **📊 Sayaç & İstatistik:** Tamamlanan Pomodoro turlarını otomatik sayma
- **🔔 Bildirim:** Süre bittiğinde açılan uyarı penceresi
- **🎨 Özel Arayüz:** QSS (Qt Stil Şablonları) ile hazırlanmış şık butonlar ve renk teması

## 📦 Kurulum ve Çalıştırma

1. **Gereksinimler:**
   Python'ın ve `PyQt5` kütüphanesinin yüklü olduğundan emin olun:
   ```bash
   pip install PyQt5
   ```

2. **Uygulamayı Başlatma:**
   ```bash
   python pomodoro.py
   ```

## 🛠️ Kullanılan Teknolojiler
- **Python 3**
- **PyQt5**
